# Customer Churn Analysis (SQL Project)

## 📌 Project Overview
This project analyzes customer churn behavior using a telecom customer dataset containing 7,000+ records. The goal is to identify patterns behind customer attrition and provide business-driven recommendations to improve retention.

The analysis focuses on customer tenure, pricing behavior, contract types, and customer segmentation using SQL.

---

## 🛠 Tools & Skills Used
- SQL (SQLite)
- Data Analysis
- Customer Segmentation
- Aggregations & CASE Statements
- Business KPI Analysis

---

## 📊 Business Questions Solved
- What percentage of customers churn?
- Which contract types experience the highest churn?
- Do pricing levels influence churn behavior?
- Are new customers more likely to leave?
- Which customer profiles represent the highest churn risk?

---

## 🔍 Key Insights
- Month-to-month contracts show the highest churn rates.
- New customers have significantly higher churn compared to long-term customers.
- Higher-priced plans experience increased churn risk.
- The highest-risk group consists of new customers on high-priced month-to-month contracts.

---

## 💡 Business Recommendations
- Improve onboarding experience during the first 3–6 months.
- Encourage long-term contracts through incentives.
- Provide early retention offers for premium-plan customers.
- Monitor high-value new customers proactively.
